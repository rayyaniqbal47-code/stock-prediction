# Stock Market Prediction Portal

## Description
Stock Market Prediction Portal is a full-stack web application built using Python, Django REST Framework, and ReactJS. The system uses an LSTM-based deep learning model to predict future stock prices based on 10+ years of historical market data.

It provides real-time predictions through REST APIs and an interactive ReactJS frontend for dynamic data visualization and user interaction.

## Features
- LSTM-based stock price prediction model
- Uses 10+ years of historical stock market data
- Data preprocessing including:
  - Handling missing values
  - Moving averages
  - Feature scaling (normalization)
- Django REST APIs for serving predictions
- ReactJS frontend for interactive UI
- Dynamic data visualization using charts
- Model performance evaluation and analysis
